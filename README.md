# Library Management System

## Project Overview
A SQL project that manages a library system including books, members, employees and branches.

## Database
PostgreSQL

## Skills Used
- SELECT, WHERE, GROUP BY, HAVING
- JOINs across multiple tables
- Subqueries
- CASE statements
- CTAS (Create Table As Select)
- Stored Procedures
- Date functions and Intervals

## Tasks Completed
- CRUD Operations (Create, Read, Update, Delete)
- Data Analysis Queries
- Branch Performance Report
- Overdue Books and Fine Calculation
- Stored Procedures for issuing and returning books
